## 📖 About

**Data Islamic JSON** adalah repository yang menyediakan berbagai dataset bertema Islam dengan format JSON agar mudah diintegrasikan ke dalam proyek pemrograman.

Repository ini dapat dimanfaatkan sebagai sumber data untuk aplikasi Al-Qur'an, kumpulan doa harian, pembelajaran Islam, pencarian hadis, dan pengembangan layanan digital Islami.

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/USERNAME/data-islamic-json.git
```

Ganti `USERNAME` dengan username GitHub pemilik repository.

### 2. Masuk ke Direktori

```bash
cd data-islamic-json
```

### 3. Gunakan Data JSON

Contoh membaca data menggunakan JavaScript dan Node.js:

```javascript
const asmaulHusna = require('./asmaulhusna.json');

console.log(asmaulHusna);
```

Untuk proyek berbasis ES Modules:

```javascript
import asmaulHusna from './asmaulhusna.json' with { type: 'json' };

console.log(asmaulHusna);
```

**Catatan:** Sesuaikan metode impor dengan versi Node.js, lingkungan proyek, dan struktur data JSON yang digunakan.
